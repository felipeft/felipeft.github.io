Sobre Mim

Engenheiro de Software com foco em Full Stack e forte base em Dados

Sou graduado em Engenharia de Computação pela Universidade Federal do Ceará (UFC). Meu foco profissional principal está na Engenharia de Software e no Desenvolvimento Full Stack, dedicando-me a arquitetar, desenvolver e integrar sistemas eficientes e escaláveis.

Tenho sólida experiência prática com desenvolvimento backend e frontend, atuando diretamente na criação de APIs REST, arquitetura em camadas e programação orientada a objetos. Utilizo com frequência tecnologias como Java, Python, JavaScript, TypeScript, React e FastAPI, além de possuir domínio em bancos de dados como PostgreSQL, MySQL, SQL Server e SQLite, com deploy em ambientes usando Git e Docker. Também carrego experiência acadêmica com desenvolvimento backend e Android em Java.

Como um diferencial no meu perfil, possuo uma segunda área forte de conhecimento em Ciência de Dados e Engenharia de Dados. Essa competência complementar inclui a utilização de Python, Pandas, modelagem preditiva, Machine Learning e processos de ETL. Isso me permite não apenas desenvolver o software estrutural de ponta a ponta, mas também compreender e integrar soluções de inteligência de dados aos sistemas.

Meu objetivo é aplicar minha expertise principal em Engenharia de Software e Desenvolvimento Full Stack para resolver problemas complexos, criar arquiteturas limpas e entregar produtos de alto impacto, utilizando o ecossistema de Dados como um forte aliado na construção de aplicações completas.
